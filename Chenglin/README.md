# Chenglin Chu — College Football Guarantee Games

This folder contains my Milestone 2 work for the IS310 semester project, **The Business of College Sports**.

## Files

- [`guarantee_games.csv`](guarantee_games.csv) — initial custom dataset of 2024 FBS-home vs FCS-away guarantee games
- [`check_dataset.py`](check_dataset.py) — Python script used to check record count, payout missingness, score differences, scope, and duplicates
- [`milestone2.md`](milestone2.md) — project documentation, transformations, audit plan, reflection, next steps, and scholarly context
